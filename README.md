## 🏥 Descripción

Sistema de gestión clínica desarrollado para optimizar la administración de hospitales, clínicas y consultorios médicos.  
Permite gestionar pacientes, personal médico, citas, historiales clínicos y procesos administrativos desde una sola plataforma.

---

## 🚀 Características Principales

### 👨‍⚕️ Gestión de Pacientes
- Registro de pacientes
- Historial clínico digital
- Seguimiento de consultas
- Control de altas y bajas

### 🗓️ Gestión de Citas
- Agenda médica
- Programación de consultas
- Control de disponibilidad

### 🧪 Área Médica
- Diagnósticos clínicos
- Registro de signos vitales
- Prescripciones médicas
- Resultados de laboratorio

### 💊 Administración
- Gestión de personal
- Control de inventario médico
- Reportes administrativos
- Control de pagos

---

## 🛠️ Tecnologías Utilizadas

- TypeScript (principal)
- LESS (estilos)
- JavaScript (scripts auxiliares)
